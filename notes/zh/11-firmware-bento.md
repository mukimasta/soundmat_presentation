# 11 · FIRMWARE — 边缘桥梁 (`11-firmware-bento`)

- **时长**：约 45 秒（按空格 3 拍）
- **上接**：`09-spine-firmware`（系统 zoom 里点到 Firmware）
- **下接**：软件 / 声音化

## 屏上（3 拍 · SPACE）

1. **Role** — 大图：传感器 → ESP32 → Pi；图上 **signal**（非 scan）。右侧四条：Signal / Send / Receive / Light。
2. **Link** — 大图：Pi ↔ ESP32 **双向** UART（上绿 S 上送、下金 L 下送），921600。
3. **Protocol** — 大字 **S** / **L**，各一句 payload + 一行示例；脚注一句校验规则。

## 讲稿

**拍 1**  
固件不是做音乐的地方。垫子里的 **ESP32** 读**信号**（图上 signal）、送给 Pi、收回 LED、点灯。音乐在 Pi 上算。

**拍 2**  
**一根 UART**，**双向**：绿线 S 帧压力上送，金线 L 帧颜色下送，同时跑。不讲引脚表。

**拍 3**  
就记两个字母：**S** = 256 压力值，**L** = 108 颜色；底下脚注：ASCII + 校验，坏了就丢。
